# Lattice

A rendering / game engine built in public as a learning challenge.

> **Design & documentation** lives in a separate repository:
> [Lattice-Engine/docs](https://github.com/LatticeEngine/docs)
> — vision, architecture decisions (ADRs) and module map.
> Those design documents are written in **French**, the author's working
> language; this README is in English so the project stays approachable.

## What is this?

Lattice is a C++ engine developed as part of a long-form learning project,
streamed and documented publicly. It is not a finished product — it's a
vehicle for learning engine programming: RHI, rendering, math, physics,
and more. See the [vision](https://github.com/LatticeEngine/docs/blob/main/VISION.md)
for the full intent.
