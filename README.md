# Lattice

A rendering / game engine built in public as a learning challenge.

> **Design & documentation** lives in a separate repository:
> [LatticeEngine/docs](https://github.com/LatticeEngine/docs)
> — architecture decisions (ADRs) and diagrams.
>
> **API reference** (generated by Doxygen from `main`):
> <https://latticeengine.github.io/engine/>

## What is this?

Lattice is a C++ engine developed as part of a long-form learning project,
streamed and documented publicly. It is not a finished product — it's a
vehicle for learning engine programming: RHI, rendering, math, physics,
and more.

## Status

Early bring-up. 🚧

## Building

Requires CMake ≥ 3.20 and a C++20 compiler (tested with MSVC / Visual Studio 2022).

```bash
cmake -S . -B build
cmake --build build --config Debug
ctest --test-dir build -C Debug --output-on-failure
```

| Option | Default | Effect |
|---|---|---|
| `LATTICE_BUILD_TESTS` | `ON` | Builds the unit tests (fetches [GoogleTest](https://github.com/google/googletest) at configure time) |
| `LATTICE_WARNINGS_AS_ERRORS` | `OFF` | Treats compiler warnings as errors |
| `LATTICE_BUILD_DOCUMENTATION` | `OFF` | Adds the `lattice_docs` target (requires [Doxygen](https://www.doxygen.nl) and [Graphviz](https://graphviz.org)) |

Targets: `lattice_core` (engine library), `lattice_app` (sandbox), `lattice_tests`, `lattice_docs`.
